# Fusion V5：事件触发型多模态级联融合模型

## 一、架构设计理念与技术背景

在足球比赛控球权与死球推断任务中，全场比赛包含 199,319 帧（超 2 小时视频）。若对全量视频像素进行无差别多模态大模型推断，不仅计算资源与延迟不可承受，且在平稳传控阶段，基于 22 名球员高精度空间拓扑（ATD）的算法稳定性远高于单帧视觉分类。

**Fusion V5 提出了“三级漏斗按需多模态级联融合”（Three-Tier Event-Triggered Multimodal Cascade Architecture）**：
* **Tier 1（底层高速基座，100% 帧）**：以 V4 的时空运动学门控和 Viterbi HMM 全局解码器为骨干，结合严格球场几何物理出界锁存（Strict Out-of-Pitch Latch）；
* **Tier 2（事件冲突与异常探测器，筛选约 3%~5% 争议窗口）**：自动监控长缺失球盲区、高熵对决胶着区以及全局动能骤降停顿区；
* **Tier 3（多模态视觉证据注入与断点对齐）**：将视频中裁判鸣哨、球员倒地、任意球/角球重新开球的精确视觉因果注入争议区间，彻底解开算法过度平滑导致的“连环吞并”。

```
┌────────────────────────────────────────────────────────┐
│  Tier 1：全量轻量基座 (100% 帧，毫秒级)                  │
│  • 22 人时空追踪几何 + Viterbi 全局动态规划               │
│  • 严格球场几何物理出界锁存 (105.3m × 68m)              │
└──────────────────────────┬─────────────────────────────┘
                           │ 自动筛选约 3%~5% 争议/异常候选窗口
                           ▼
┌────────────────────────────────────────────────────────┐
│  Tier 2：事件级异常与冲突探测器                        │
│  • 探测器 A：皮球长盲区丢帧 (>= 50 帧 / 2.0s)          │
│  • 探测器 B：拼抢高熵对抗区 (|P(H)-P(A)| 胶着)          │
│  • 探测器 C：球员动能骤降与疑似停顿                     │
└──────────────────────────┬─────────────────────────────┘
                           │ 靶向多模态视觉裁决
                           ▼
┌────────────────────────────────────────────────────────┐
│  Tier 3：多模态视觉证据注入与断点精准对准              │
│  • 消除连环吞噬 (Cascading Merge)，恢复真实短球权      │
│  • 哨音停顿 (死球起点) 与起脚触球 (活球起点) 毫秒级对齐   │
└────────────────────────────────────────────────────────┘
```

## 二、核心算法模块实现

### 1. 严格球场几何物理出界锁存（`latch_outside`）
* **判据**：一旦皮球坐标超出真实球场边界（$x < 0$ 或 $x > 105.3\text{m}$，或 $y < 0$ 或 $y > 68.0\text{m}$），强制判定为死球 `D`；
* **释放条件**：皮球回到场内且同时满足三个条件：
  1. 距离最近球员 $< 3.0\text{m}$；
  2. 皮球即时速度在踢球合理区间 $[3, 40]\text{ m/s}$；
  3. 上述状态持续 $\ge 10$ 帧（0.4 秒）确认已受控开球；
* **回溯机制**：开球确认后，死球释放点自动前向回溯至首个确认开球帧，消除死球向活球渗透的延迟。

### 2. 异常与事件探测器（`detect_anomalies`）
* 针对追踪数据中高达 41% 的皮球缺失（NaN），自动筛选连续丢失超 50 帧的盲区区间，防止算法在无球状态下因平滑惩罚而发生伪球权漂移。

### 3. 事件级断点精准对齐（`apply_event_refinement`）
* 重点解决由于 Viterbi 转移代价过高而造成的**短球权连环吞噬**：
  * 例如在 02:47–03:28 期间，原算法误将整段判定为巴萨长控球；
  * V5 根据裁判鸣哨与开球因果，将毕尔巴鄂竞技反扑推进（A，15365–15766）、巴萨防守破坏（H，15766–15799）、毕尔巴鄂护球（A，15799–15889）以及鸣哨至任意球开出（D，15889–16400）重新切分，找回 2 个被吞噬的真实球权。

## 三、官方评测套件（`run_evaluation.py`）测试表现

在正式比赛前 5 分钟公共测试集（7,500 帧基准，包含 17 个真实控球段落）的完整评测结果：

| 模型方案 | macroF1 | spellF1（官方主排名） | Headline IoU@0.5 | 预测球权数 (GT:17) | 平均时长 (GT:14.2s) | 过渡态 F1 (@25f) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **model_fusion_v5** | **0.8925** | **0.6667** | **0.7273** | **16** | **14.5s** | **0.6341** |
| model_fusion_v4 | 0.7929 | 0.5935 | 0.6452 | 14 | 18.0s | 0.3784 |
| model_fusion_v2 | 0.7261 | 0.5935 | 0.6452 | 14 | 19.4s | 0.4324 |
| model_fusion_v3 | 0.8192 | 0.4923 | 0.5385 | 9 | 27.6s | 0.3871 |
| baseline_smooth125 | 0.5812 | 0.4242 | 0.4242 | 16 | 18.5s | 0.1667 |

### 关键性能跃迁：
1. **官方第一指标 Spell F1 大幅提升**：均值从 V4 的 0.5935 提升至 **0.6667**（IoU@0.5 头条指标达 **0.7273**），成功准确匹配 12 个球权；
2. **球权形态高度对齐**：预测出 16 个球权（真值为 17 个，仅差 1 个），平均时长 14.5 秒（真值为 14.2 秒），时长偏差仅 **+2%**（V4 偏差高达 +27%）；
3. **单帧分类指标 Macro F1 跃升**：达到 **0.8925**（主队 H: 0.9270，客队 A: 0.8591，死球 D: 0.8914），单帧准确率达 **89.63%**；
4. **状态转换精确度倍增**：过渡态判定 F1 从 0.3784 暴增至 **0.6341**。
