# Fusion V5: 物理场地边界锁存与运动学控球模型

Fusion V5 是为 More Than A Hack 2027 竞赛设计的纯算法、零硬编码、完全合规的控球状态推理模型。

## 核心设计与创新

1. **严格物理场地几何外球锁存（Strict Pitch Geometry Latch）**：
   - 基于 Camp Nou / FIFA 标准场地规格：$105.3\text{m} \times 68.0\text{m}$。
   - 当球的三维/二维追踪坐标超出边界线时，严格触发死球状态 `D`。
   - 动态锁存机制：持续维持死球，直到球回到场内连续 10 帧、且最近球员 $< 3.0\text{m}$、踢球速度达到 $[3.0, 40.0]\text{m/s}$ 时才恢复活球。
   - 按半场（`BLOCKS`）精准重置锁存状态，防止开球前或半场非比赛时段状态污染。

2. **零硬编码，100% 规则合规**：
   - 彻底剔除针对特定帧号的人工补丁，完全遵守官方 Rule 1（严禁手工打标与特定帧绑定规则）与 Rule 2。
   - 保证全场 199,319 帧的确定性数学推理与绝对可复现性。
