# V6: V5 + restart-head latch

V6 promotes the evaluated `tag_head` experiment without threshold changes. It is now
the default selected by `run_pipeline.py --model auto`; V5 remains available with
`--model v5`. Run V6 explicitly with `python run_pipeline.py --model v6`.

V6 first runs V5 with experimental refinements disabled, then sets qualifying restart
preparation frames to D. It uses every Smart Tagging SET PIECES type, including throws
and goal kicks. Entry is restricted to the first half of a tagged interval, with at
least 18 visible player tracks and mean speed below 0.8 m/s. It releases on observed
ball speed crossing 8 m/s (speeds above 40 m/s are discarded), a previously slow
ball-near taker accelerating past 3.5 m/s, or the end of the tagged interval. Missing
ball samples are not interpolated. The player-only experiment is not enabled.

This is a dead-ball inference heuristic, not proof of a whistle or exact kick time.
It inherits automatic tagging errors and can extend D into live play. In particular,
it does not rename the provided Free Kick tag to Penalty. A missing ball can delay
release until the ball reappears.

Validation: full-match output (199319 rows) passes submission validation and is
byte-identical to `evaluation/v5_restart_experiments/tag_head.csv`. Two V6 integration
tests and three restart tests pass. Public five-minute results: macro F1 0.8025,
spell F1 0.6125, D precision 0.8422, D recall 0.6467. These are not full-match scores.
Compared with V5, 1068 frames change; on the public window 28 are corrected and 44
previously correct live frames become incorrect D. This version is a chosen iteration,
not a demonstrated improvement in overall accuracy.

Outputs: `evaluation/results/model_fusion_v6.csv`; run report, configuration and source
hashes in `evaluation/v6_latest_run/`. `predict_with_audit()` also returns latch events.
