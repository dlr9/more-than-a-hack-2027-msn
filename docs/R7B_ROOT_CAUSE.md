## 四层排查与证据

1. **对齐**：从原始公开 JSONL 重建 timeline，逐元素验证新旧 cache 的 frame、period，ball 坐标有限性与 ball_visible，一致。新旧 y_alive/y_home 一致；所有入选帧的 raw possession 与 phase possession 也一致。标签来自 `solution/external.py:246` 的 provider possession、`:275` 的稳定性与 phase 一致筛选，不来自最近球员预测。phase 处理为半开区间。没有发现位移或半场错配。
2. **特征支持**：在这些帧，球坐标、速度、到球队距离、局部球员速度及距离历史全部缺失；两队球员数、球附近计数全部为 0。`solution/features.py:95`、`:100`、`:104` 显示旧特征以球为中心；删去 5 列不能创造运动证据。独立 DFL dropout 训练缓存里缺球帧 WPY/WOH/WQQ 为 18028/17119/17692，但**没有一帧同时零球员**；其源 Alive 比例为 .51287/.50242/.58043。因而当前失败包含严重观测支持分布迁移，不能简单归因为 class prior。
3. **概率与联合 argmax**：M2/M3 的 p_alive 均值 .4272095，范围 .4159426–.4275672，p_home 恒为 .4625884。平均联合概率为 `[H=.1976222,A=.2295874,D=.5727905]`，argmax D=195/195。公式在 `solution/decoder.py:11`；没有发现类别顺序/乘法错误。由于活球概率被 H/A 两队分摊，单独 p_alive>.5 也不足以保证联合 argmax 不选 D。
4. **解码**：M2/M3 decoded D=195/195，与 raw argmax 相同。`solution/idsse_model.py:13` 的 M3 只扩大 D 转换代价，不修改发射概率。新的真实 decoder 合成回归测试说明：125 帧持续强 D 的证据仍压倒 ×4 边界代价；修正 Alive 发射后同一 decoder 能保留 H。Viterbi 不是这次全 D 的首要来源。

对照也不能误读：M1 p_alive=.99793，D=0，但缺球 H/A 准确率只有 .09744；M4 p_alive=.76798，D=1/195，依赖几乎固定 H/A 先验且这些已知帧 176/195 属 H。它们不是充分的缺球控制证据。M5/M6 同样 raw 与 decoded 全 D。

## 标签独立性及结论边界

特征不读取 possession/phase/status；标签筛选也不读取检测球坐标。但供应商 possession 的上游生成机制不能证明独立于其追踪流程，phase 非完整有效控制真值，已知标签选择还依赖稳定 possession 可用性。因此只能报告来源已知活球的假 D，不能据此证明实际比赛一定仍在进行，更不能算完整 spellF1。所有前后可见帧概率已逐段留在 JSON。

**决定：优先修复可观测条件下的 Alive 证据，保留全部旧模型。** 真 Player-only 从原始球员轨迹训练，覆盖“缺球但球员可见”；零球员段必须被标为无证据，不能把 HGB 的 missing 分支输出当作运动判断。质量门控必须同时考虑球员可用性。随后独立测试有边界和失效条件的时序延续，严格计入真实死球漏检；不继续盲调 M3 ×4。
