2. 任务理解与评价指标

目标是为目标比赛每个视频帧输出 H、A、D 或 X：

  • H / A：活球时主队或客队拥有 controlled possession。
  • D：死球；即使供应商字段仍写有球队，赛事标签也必须是 D。
  • X：官方不评分区间。
  • 争抢、折射、loose ball 不立即换权；只有另一方建立 controlled possession 才切换。

MacroF1：帧级分类

分别计算 H/A/D 的 F1 后取平均，关注每个状态有多少帧预测正确。它对短暂抖动不如 SpellF1 敏感。

SpellF1：连续片段

关注整段 possession 是否与真值在时间上匹配。一个真实片段被切成多个短片段，即使大多数帧标签正确，也会明显降分。

赛事定义与评分细节见本地 CHALLENGE.md、EVALUATION.md，以及官方仓库。

5. 训练标签构造与样本选取

5.1 语义风险

赛事的 possession 是 corrected tracking 下的 controlled-possession 定义；SkillCorner 的 possession.group 是供应商逐帧估计，公开文档没有承诺两者使用相同换权规则。因此 SkillCorner 只被视为弱监督，不直接当成赛事真值。

5.2 Alive/dead 严格标签

  1. SkillCorner phase 区间按 [frame_start, frame_end) 解释。
  2. phase 内部是 raw alive；正式半场内没有 phase 的帧是 raw dead 候选。
  3. 每个 phase 起止边界前后 1 秒全部设为 unknown，不训练 alive/dead 或 H/A。
  4. 最终全量严格样本：alive 459,714，dead 508,731。

5.3 Home/away 高置信标签

只有同时满足以下条件的帧才训练 P(home | alive)：

  • 当前帧是 clean alive；
  • possession.group 已知；
  • 以当前帧为中心前后 1 秒均为同一球队；
  • possession.group 与 phase 的 team_in_possession_id 一致；
  • 不在 phase 边界、换权附近或来源冲突位置。

最终全量高置信 H/A：H 182,811，A 173,457，共 356,268 帧。两种 SkillCorner 球队来源在可比较帧上的一致率为 83.74%；严格清洗后保留率为 58.19%。

5.4 严格标签与完整弱时间线分离

y_alive / y_home

高置信、边界排除后的标签。仅这些标签进入两个分类器的 fit()。

eval_y_alive / eval_y_home

用 phase 覆盖和 phase 球队构造完整代理时间线，只用于粗粒度 SpellF1 和 Viterbi 选择，不参与分类器拟合。

5.5 Metrica 高置信样本

  • PASS、CARRY 内部去掉首尾 2 帧，作为高置信 H/A。
  • BALL OUT 结束后到下一次 SET PIECE 开始前，作为高置信 D。
  • 重叠、事件冲突或球队未知帧全部排除。
  • 得到 H 37,512、A 35,094、D 27,360；其中 72,606 个 H/A 帧用于跨供应商门槛。

6. 统一 44 维输入特征

两个分类器使用同一组 44 个特征。特征不包含球员 ID、球衣号码、比赛 ID、具体球队名称或 SkillCorner possession 字段；缺失值由 HistGradientBoosting 原生处理。

类别数量字段与意义
球基本状态5ball_visible、ball_x/y、ball_speed_mps、ball_speed_missing
可见球员数2n_home_visible、n_away_visible
最近三人距离8双方 d1/d2/d3 及最近三人均值，按真实球场长宽换算为米
局部速度2双方距球 5 米内球员的平均速度
局部人数10双方在 1/2/3/5/10 米内的球员数
最近距离差1away_d1 - home_d1，是 nearest-player 的连续形式
边界距离4球到两条底线和两条边线的米制距离
历史窗口120.2/0.5/1.0 秒内的球可见率、双方最近距离均值、球位移
合计44当前帧空间状态 + 仅使用过去信息的短时动态
跨供应商原则：同一特征函数用于 SkillCorner、Metrica 和目标 ATD；坐标先统一为归一化球场坐标，所有距离再按各自球场长宽换算为米。SkillCorner 球员速度由同一球员连续帧位置重建。

7. 模型选择与训练方案

7.1 两个概率模型

Alive/dead

HistGradientBoostingClassifier

  • 输出：P(alive)
  • max_leaf_nodes：15
  • learning_rate：0.1
  • L2：0
  • 实际迭代：300

Home/away

HistGradientBoostingClassifier

  • 输出：P(home | alive)
  • max_leaf_nodes：31
  • learning_rate：0.1
  • L2：0
  • 实际迭代：300

7.2 分类器候选网格

max_leaf_nodes     ∈ {15, 31}
learning_rate      ∈ {0.05, 0.1}
l2_regularization ∈ {0, 1}
max_iter           = 300
early_stopping     = True
random_state       = 2027

每个分类器比较 8 个组合。优先选择 validation balanced accuracy 更高的候选，其次 log loss 更低；仍相同时偏向更简单模型。训练使用逆类别频率 sample weight。两模型都运行到 300 轮上限，没有提前停止。

7.3 Viterbi 参数选择

H ↔ A penalty   ∈ {1, 2, 3, 4, 5}
H/A ↔ D penalty ∈ {0.5, 1, 2, 3}

在三场 validation 完整弱时间线上评估 20 组组合，先最大化平均 SpellF1，再比较 MacroF1、预测片段数和较小惩罚。最终选中 H↔A=5.0、H/A↔D=3.0。半场分别解码，不评分区间保持 X。

7.4 预先冻结的晋级规则

  1. SkillCorner validation 平均 SpellF1 相对 nearest-player + smooth50 至少提升 0.02。
  2. 至少 70% 的 validation 比赛 SpellF1 不下降。
  3. Metrica Game 3 高置信 H/A macroF1 不得下降超过 0.02。
  4. 全部通过后才设置 promoted=true 并首次读取 SkillCorner test。
  5. 公开 5 分钟不参与模型、阈值、Viterbi 或版本选择。

总体 Accuracy 提高 6.23 个百分点，但 H/A 正确帧合计减少 389；净提升几乎全部来自死球识别。若真值与预测都为 alive，球队准确率从 85.82% 略升到 86.63%，说明 Home 模型本身有一点增益；问题是 Alive 模型把更多真实活球判成 D。

9.2 正确解读

  • 帧级分类：模型优于阶段 A，特别是 D。
  • 活球控球队完整判断：当前 5 分钟上反而下降，不能宣称实际控球预测已显著提高。
  • 总体控球比例：误差从 4.85 个百分点降到 0.37 个百分点，但总体比例正确不等于每帧正确。
  • 连续 possession：模型显著过度分段，导致 SpellF1 低于阶段 A。

10. 不足与局限性

  1. 标签语义不完全一致。SkillCorner possession 不保证遵循赛事 controlled-possession 换权规则；边界、争抢、折射和 loose ball 是最高风险区。
  2. Viterbi 使用弱监督完整时间线。它适合比较粗粒度连续性，但 phase 边界不是 corrected tracking 真值。
  3. 目标域时序碎片化。官方 5 分钟中模型预测 43 个 possession，而真值只有 17 个。
  4. Alive 模型存在 false-dead 风险。H/A 模型在双方都判 alive 时略优，但更多真实活球被判成 D。
  5. Viterbi 最优点位于搜索上界。外部 validation 在 (5,3) 最佳，提示可能需要更强平滑；扩大网格必须成为新的预注册实验。
  6. Early stopping 未提前停止。两个模型均跑满 300 轮，需要在新交叉验证协议中研究迭代上限。
  7. 供应商域偏移仍存在。采样率、坐标质量、球缺失模式、速度重建和 phase 生成方式不同；Metrica 门槛不能覆盖完整 H/A/D 时序。
  8. 公开真值规模很小。只有 5 分钟、17 个 possession，适合暴露错误，不足以稳定排序候选，也不得用于调参。
  9. 阶段 B 尚无实证排名。已生成合法 CSV，但没有独立可比分数。
  10. 晋级不等于最终最优。model_v1 通过的是冻结的外部门槛；reference smooth50 仍是回退点。

11. 当前决策与下一步

model_v1 外部晋级

保留为最终候选。外部泛化、死球识别和帧级 MacroF1 更好，但有目标域时序碎片化。

reference_smooth50 回退点

与官方 baseline 完全一致；公开 5 分钟 SpellF1 高于 model_v1，但 MacroF1 和死球识别较低。

heuristic_v1 待验证

规则合理但尚无独立真值结果，不进入已验证候选排名。

11.1 model_v2 的合规方向

  1. 先冻结新实验假设、参数网格和晋级规则，再运行实验。
  2. 不再使用已读取的 SkillCorner test 选参；使用 train/validation 内部比赛级交叉验证或 nested CV。
  3. 重点分析 false-dead、短 D 插入和 H↔A 短抖动，不只优化 Accuracy。
  4. 研究概率校准、最短持续时间、半马尔可夫解码或显式 duration model。
  5. 同时约束 MacroF1、SpellF1、片段数、持续时间和真实活球帧球队准确率。
  6. 保持公开 5 分钟封存，不用它决定阈值、惩罚、特征或版本。
当前研发判断：保留现有 44 维特征与 Home/away 分类器，优先修复 Alive 的 false-dead 和时序解码的过度切分。现有结果既不支持完全推翻分类模型，也不支持仅增加分类器复杂度解决 SpellF1。
