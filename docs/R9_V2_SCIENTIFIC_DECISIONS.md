# R9 V2 有判别力的发现

E09-D在36个完整比赛场景、72个半场完成官方5IoU重新匹配。自然M3仅修D的诊断增量WPY/WOH/WQQ为 .0025/.0064/.0164，修正仍判活球中的队伍为 .4307/.4328/.3797。短控球缺失和HA错误优先于继续自然域Alive修补。分项干预有交互，不能相加；这些不是可部署上界，也没有保存任何oracle逐帧标签。

可观测近球区域的孤立真值修正反而降低spell .1099/.0819/.1326，说明“更多正确帧”可以切碎片段。由此先做保留片段数的E1物理边界提议，再按失败机制做一次E2有限区域时序解码。E1fix及E2均真实跑完24组，并保留原D掩码。结果不支持继续搜索物理阈值：事件支持多数是已正确的容易区域，新信息不足以修复空中球、争夺、稀疏接触等难例。

E09-A不是按旧排序假定C1 Home更好，而是一次固定2×2反证：在相同M3解码下，自然域提升实际来自Home，C1 Alive自身略差。Brier变差并不意味着片段检测一定更差。自然域M2 Home→C1 Home的预测spell数为381→339、406→383、430→416；伪HA边界143→117、172→159、162→153。在IoU .5，真匹配228→221、227→234、247→249。WPY甚至少了7个真匹配，仍因减少过多预测提高F1。因此只能归因于头部改变了片段数量/匹配取舍，不能声称普遍更准确的有效控制。

短GT(<1s)的.5IoU匹配分别4/57→6/57、9/46→6/46、4/37→6/37，仍很弱且不一致。HC_M3在12个场景没有增加漏D帧/漏完整段；这支持继续保留组件，但不证明隐藏目标收益。它也未全面超过H1的压力域结果。

E09-A2仅一次固定分层消融。M2 Alive在Metrica弱D上的分层漏检25380/25619，而联合M3为1895，混合Home后1846。现有概率未经跨域校准，拆开Alive阈值会放过大量弱D；不能用DFL高分宣称分层解码通用。SC已知195个长缺球帧仍D，且零球员/球观测不可识别，没有新增观测就不再加记忆。

决定：冻结HC_M3为研究组件，否决C1 Alive与本轮分层替代；保存事件两轮失败。停止这些重复开发场上的进一步权重/阈值搜索。下一项需要真正新的边界监督或语义相容的完整跨供应商HAD，而非更多同源反复拟合。
